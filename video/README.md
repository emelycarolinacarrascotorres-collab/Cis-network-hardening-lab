## Cómo mostrarlo en el README

- **Enlace con miniatura (recomendado):** guarde una captura como `video/thumbnail.png` y use
  `[![Ver video](video/thumbnail.png)](LINK_DEL_VIDEO)` en el README.
- **Video incrustado:** en GitHub, edite el README en el navegador y arrastre el `.mp4` (menor a 100 MB) al editor; GitHub genera un enlace que se reproduce dentro de la página.
- Si el video es público, verifique antes que no muestre contraseñas ni datos personales.
